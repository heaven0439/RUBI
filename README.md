# RUBI
R.U.B.I. (Responsive Utility &amp; Behavioral Intelligence) is a voice-controlled local AI desktop assistant for Windows, powered by Ollama (Qwen 2.5). It offers hands-free interaction, desktop automation, real-time system monitoring, voice typing, and web searches through a futuristic interface. Built with Python, FastAPI, WebSockets, and JavaScript.
## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, FastAPI, Uvicorn
- **Communication:** WebSockets
- **AI:** Ollama, Qwen 2.5 (1.5B), HTTPX
- **Voice:** SpeechRecognition, PyAudio, pyttsx3
- **Automation:** PyAutoGUI, subprocess
- **Monitoring:** psutil
- **Platform:** Windows
